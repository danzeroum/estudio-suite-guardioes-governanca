# roteirista — entradas

- `filmes/<id>/pedido.md` — a história como ela chegou.
- `python3 -m estudio_suite inventario` — o que o motor sabe fazer. **Lido, nunca suposto.**
- `workspace/lei/docs/assets/data/lgpd-arts.json` — o texto literal dos artigos.
- `workspace/lei/docs/assets/data/gap-matrix.json` — quem responde por cada artigo.
- `filmes/*/roteiro.md` dos filmes existentes — o formato, o tom e o ritmo já aprovados.

Não lê `motor/`: o que ele precisa saber do motor está no inventário, e ler o código o
tentaria a usar o que o inventário não mostra.
