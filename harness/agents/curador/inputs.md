# curador — entradas

- `harness/runs/*.json` — o acumulado das execuções: o que reprovou, quantas vezes, onde.
- `filmes/*/relatorio.json` — a evidência por filme.
- `filmes/*/local/` — os adereços que cada história precisou inventar.
- `python3 -c "from estudio_suite import orcamento; orcamento.main()"` — a folga de cada arquivo.
- `harness/change-proposals/` — o que já foi proposto, para não propor duas vezes.

Não lê `motor/` para julgá-lo. O estado do motor que lhe interessa vem medido, não lido.
