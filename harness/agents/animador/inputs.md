# animador — entradas

- `filmes/<id>/roteiro.md` — a shot list é o contrato; o dado a implementa.
- `python3 -m estudio_suite inventario` — poses, expressões, cenários, props e o
  vocabulário aceito (`acoes`, `numericas`, `eventos`, `easings`, `camadas`).
- `filmes/<id>/local/` — o que o diretor de arte criou para este filme.
- `filmes/*/*.filme.js` existentes — a convenção de ritmo, zoom e entrada.
