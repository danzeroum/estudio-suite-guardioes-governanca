# animador — saídas

- `filmes/<id>/<id>.filme.js` — JSON estrito depois de um prefixo de uma linha. O mesmo
  arquivo é carregado pelo navegador e lido pelo validador: uma fonte, dois leitores.
- `filmes/<id>/baseline/*.txt` — as referências de palco, por `--gravar`.
- `filmes/<id>/relatorio.json` — escrito pelo teste, não à mão.
